# Machine-Learning na área da saúde

Projeto: Previsão de Doenças Cardíacas com Machine Learning

Resumo:

Este projeto aplica técnicas de aprendizado de máquina para prever o risco de doenças cardíacas com base em dados clínicos.
A iniciativa busca apoiar a área da saúde com uma abordagem preditiva, utilizando variáveis como idade, sexo, pressão arterial, colesterol, glicemia e resultados de exames.

Objetivo

Desenvolver e avaliar modelos de classificação capazes de identificar pacientes com maior probabilidade de desenvolver doenças cardiovasculares, auxiliando em diagnósticos precoces e medidas preventivas.

Principais Etapas

Limpeza e tratamento dos dados clínicos.
Análise exploratória (EDA) para identificação de padrões.
Treinamento de modelos de Machine Learning (ex.: Random Forest, XGBoost).
Avaliação de desempenho com métricas de precisão e acurácia.

Tecnologias Utilizadas

Python 3
Pandas, NumPy – Manipulação e análise de dados
Matplotlib, Seaborn – Visualização gráfica
Scikit-learn – Modelagem e avaliação de modelos de ML
Google Colab / Jupyter Notebook

Dataset

O projeto utiliza o conjunto de dados Heart Disease (UCI Machine Learning Repository), contendo variáveis clínicas relacionadas à presença ou ausência de doença cardíaca.

Conclusão 

Através da análise completa realizada neste projeto, foi possível identificar os principais fatores que contribuem para o desenvolvimento de doenças cardíacas:

Fatores Demográficos:

Idade: Pacientes mais velhos apresentam maior predisposição

Sexo Masculino: Representou aproximadamente 70% dos casos analisados

Indicadores Clínicos Diretos:

Tipo de Dor no Peito: Dores do tipo anginosa (tipos 1, 2 e 3) mostraram forte correlação com problemas cardíacos

Depressão do Segmento ST: Valores elevados indicam alterações isquêmicas significativas

Número de Vasos Principais Atingidos: Quantidade superior de vasos comprometidos aumenta drasticamente o risco

Talassemia: Anomalias na talassemia mostraram-se como importante preditor

Marcadores Metabólicos e Fisiológicos:

Colesterol Elevado: Média de 246 mg/dl na população de risco

Pressão Arterial em Repouso: Valores limítrofes ou elevados (média de 131 mmHg)

Frequência Cardíaca Máxima Reduzida: Capacidade cardíaca comprometida durante esforço

Angina Induzida por Exercício: Presente em 33% dos pacientes com problemas cardíacos

Outros Indicadores Relevantes:

Nível de Açúcar no Sangue em Jejum: Glicose elevada em 15% dos casos

Resultados Anormais no Eletrocardiograma: Alterações na condução elétrica cardíaca

Os modelos de machine learning desenvolvidos, particularmente Random Forest, demonstraram capacidade preditiva excepcional, com altas taxas de acurácia, precisão e recall. A análise de clustering complementar revelou padrões ocultos nos dados, permitindo identificar subgrupos de pacientes com características clínicas similares.

Esta solução tecnológica representa um avanço significativo na detecção precoce de riscos cardiovasculares, oferecendo uma ferramenta acessível e eficiente que pode ser implementada em unidades de saúde básicas, potencialmente salvando vidas através da intervenção preventiva e tratamento oportuno.
